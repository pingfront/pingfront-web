# Security

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- on GitHub: this repository's **Security** tab › **Report a vulnerability**, or
- by email to hello@pingfront.sh, with "Security" in the subject.

Include the version you used, the steps or a proof of concept that shows the problem, and what an attacker
could do with it. We confirm every report, keep you posted while we fix it, and tell you when the fix ships.
If you'd like credit in the advisory, say so.

## Supported versions

Security fixes go into the latest release. Update to it to get them.

## Scope

This repository's code. Problems in the pingfront service itself (the API, the dashboard or the web widget's
CDN) can be reported the same way.
